# Shubham Saini — Developer Portfolio

A responsive developer portfolio built with **Next.js App Router**, **TypeScript**, and **Tailwind CSS**. It presents Shubham’s real projects, experience, services, skills, GitHub activity, resume, and contact options in a dark neon interface.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Use `npm run build` to create a production build and `npm start` to serve it.

## GitHub contribution calendar

Public repository language stats load without configuration. To show the contribution calendar, set `NEXT_PUBLIC_GITHUB_TOKEN` to a read-only GitHub token in `.env.local` (see `.env.example`). This value is exposed to the browser by design and must not have write permissions.

## Contact form

The contact form uses the portfolio’s existing EmailJS service and template configuration.
